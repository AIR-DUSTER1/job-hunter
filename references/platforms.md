# 平台适配参考

只在需要调整适配器时读这份。正常采集不需要。

## 字段在各个平台的真实位置

这张表是逐平台实测出来的，调整适配器前先看它，不要靠猜 DOM：

| 字段 | BOSS | 智联 | 51job | 猎聘 |
|---|---|---|---|---|
| 投递链接 | 卡片 `a.job-name[href]` | Vue `positionURL` | `sensorsdata.jobId` 拼 | 卡片 `href` |
| 上架时间 | **公司页「职位列表第一个职位更新时间」** | **Vue `publishTime`（精确到秒）** | **`sensorsdata.jobTime`（精确到秒）** | 详情「N天前更新」 |
| HR 活跃 | 面板 `.boss-active-time` | **发布者区 `__online` + `__activity-tag`** | 卡片 `.tip`（回复率高） | 详情「N小时前在线」 |
| HR 姓名 | 面板文本「X女士」 | 发布者区 `__name` + `__job-title` | ✗ | 详情「X女士」 |
| 公司规模 | **公司页三元组** | **公司信息 `B轮 · 300-499人 · 行业`** | 卡片 `.dc` | 详情「人数规模：」 |
| 行业 | **公司页三元组** | 同上 | 卡片 `.dc` | 详情「企业行业：」 |
| 融资阶段 | **公司页三元组** | 同上 | 卡片 `.dc` | 详情卡片文本 |
| 公司简介 | 公司页 `.job-sec` | 点击面板「公司介绍」 | 详情「公司信息」段 | 详情公司区 |
| 单双休 | **公司页 `.job-sec.work-time`** | JD「薪资福利」段 | **福利标签**（周末双休） | JD |
| 上下班时间 | **公司页 `.job-sec.work-time`（上午09:00-下午06:00）** | JD | JD | JD |
| 岗位福利 | **公司页 `.job-sec.work-time`（十余项标签）** | JD「薪资福利」段解析 | **标签分类提取** | JD 关键词扫描 |
| 工作地址 | 面板「工作地址」 | 面板 | 详情「地图完整地址：」 | **详情「职位地址：」** |

**加粗**的是该字段最可靠的来源。✗ 表示平台确实不提供，不要浪费时间找。

两个非显然的点：

- **BOSS 的福利和工时不在岗位页，在公司页**。`/gongsi/xxx` 的
  `.job-sec.work-time` 区块同时给出作息和十余项福利标签，是四个平台里
  最完整的福利来源，比岗位详情页值得抓。
- **智联的 HR 活跃在「职位发布者」区**（`.job-detail-publisher`），
  不在 JD 面板里。能拿到「在线·今日回复50+次·高回复率」这种组合信息。



每个平台的编码体系完全不同，必须分别维护。

### 新增城市

1. BOSS：打开目标城市职位页，地址栏 `city=` 后的数字
2. 智联：访问 `https://www.zhaopin.com/<城市拼音>/`，页面里 `/sou/jl<数字>` 的即 jl 码
3. 51job：搜索后看地址栏 `jobArea=` 的值
4. 猎聘：打开 `https://www.liepin.com/city-<城市拼音>/`，点「职位」后的 URL 里 `dq=` 的值

然后加到对应适配器顶部的 `CITY_*` 字典：

```python
# adapters/boss.py
CITY_CODE = {"青岛": "101120200", "新城市": "编码"}
```

## BOSS 直聘

**数据分三处**，列表卡片信息最少，必须补另外两处：

| 位置 | 能拿到 |
|---|---|
| 列表卡片 `.job-card-wrap` | 岗位、薪资（需解码）、经验、学历、公司名、地区、详情链接、公司页链接 |
| 点击卡片后的右侧面板 | **JD、工作地址、HR 姓名、`.boss-active-time` 活跃状态** |
| 公司页 `/gongsi/xxx` | **融资 + 规模 + 行业三元组、公司简介** |

### 详情必须点卡片，不要直接开 job_detail

`job_detail` 页有独立反爬，直接 `page.get()` 大概率被重定向回首页。
点列表卡片只是 SPA 内切换右侧面板，不会触发跳转，可靠性高得多。

一页只有 15 张卡片，而清单可能有几十条。所以**每条都要按岗位名重新搜一次**
（`BASE?query=<岗位名>&city=<code>`），否则后半截找不到卡片。改之前命中率约
3/20，改成逐条搜索后是 8/10。

### 公司信息在公司页，格式固定

访问卡片里的 `a[href*="/gongsi/"]`，页面上有一行固定格式：

```
未融资 20-99人 电子商务
```

依次是 **融资阶段 / 规模 / 行业**。正则：

```python
r"(未融资|不需要融资|天使轮|A轮|B轮|C轮|D轮|E轮|已上市|战略融资|融资未公开|IPO上市)"
r"\s*(\d+-\d+人|少于\d+人|\d+人以上)"
r"\s*([\u4e00-\u9fa5A-Za-z/、,+ ]{2,20})"
```

公司页按公司名去重——同公司多个岗位只查一次。

### 薪资是字体混淆的

薪资数字被替换成 Unicode 私有区字符，页面上显示成 `K` 或空白。映射关系：

```
U+E031 → 0
U+E032 → 1
...
U+E039 → 8
```

即 `码点 - 0xE031 = 数字`。这个偏移在多次页面加载间稳定（已验证连续三次加载）。
解码在 `adapters/boss.py::decode_obfuscated`。

**不要**改成读 `innerText` 或 `text`——拿到的就是这些私有区字符，不做解码结果是乱码。

### JD 里随机插了站点名水印

正文会被插成「流BOSS直聘程编排」这种（水印在词中间，不是完整短语）。
去空白后要先 `replace("BOSS直聘", "")` 再 `replace("直聘", "")`，
用 `_clean_watermark()` 处理。只删「来自BOSS直聘」是不够的。

### 卡片文本形态

```
AI Agent开发工程师10-15K    ← 岗位名 + 薪资（薪资部分需解码）
3-5年                       ← 经验
本科                        ← 学历
中信恒 青岛·李沧区·李村公园   ← 公司名 + 城市·区·商圈
```

公司名和地区在同一行，用空格分隔，解析时用正则
`^([\u4e00-\u9fa5A-Za-z0-9（）()]{2,26})\s+([\u4e00-\u9fa5]{2,8}·.+)$` 一次拿全。

### 必须登录

未登录时列表页被 `_security_check` 重定向，`card 数量为 0`。
登录成功判据：`xpath://a[@href="https://www.zhipin.com/web/geek/recommend"]//img` 存在。
只判断"页面没有『登录/注册』字样"会误判——安全校验页也没有这个字样。

### 详情页限流

详情页 `job_detail` 连续访问 3 次可能被重定向回首页。
`enrich` 里连续 3 次拿不到内容就停止，不要重试。

## 智联招聘

**这个平台改了实现方式，注意别改回去。**

### 链接和完整数据在 Vue 里，不在 DOM

卡片 DOM 只有岗位名、薪资、技能标签，**没有 jobId、没有详情 URL、没有发布时间**。
完整数据挂在列表组件的 props 上：

```js
document.querySelector(".job-card").parentElement.__vue__.$props.list
```

每项含 100+ 字段，常用的：

| 字段 | 含义 | 示例 |
|---|---|---|
| `name` | 岗位名 | AI智能体开发工程师 |
| `jobId` | 岗位 ID | 40873965603 |
| `positionURL` | **投递链接** | https://www.zhaopin.com/jobdetail/CC... |
| `publishTime` | **上架时间** | 2026-10-31 01:21:17 |
| `jobDescription` | JD 摘要 | 岗位职责1.平台设计与开发... |
| `salary60` | 薪资（人读） | 1.2-2.2万 |
| `salaryReal` | 薪资（数字） | 12001-22000 |
| `companyName` / `companySize` / `industryName` / `financingStage` | 公司信息 | |
| `workingExp` / `education` | 经验学历 | |
| `jobSkillTags` | 技能标签（对象数组，取 `.name`） | |
| `welfareLabel` | 福利 | 列表页通常是空数组 |

实现在 `adapters/zhilian.py::_READ_LIST_JS`。卡片文本解析保留为兜底，但**那条路拿不到链接**。

### 详情页有人机验证，改点卡片

`jobdetail` 页挂了腾讯云 EdgeOne，直接访问返回"正在验证连接安全性，请勾选下方复选框"。
所以**不要逐条打开详情页**。

改用**点击列表卡片**，右侧弹出 `.job-detail-modules__body` 面板，里面有：

- 公司介绍全文
- JD 全文（比 Vue 数据里的摘要更完整）
- 公司信息行：`未融资 · 20-99人 · 软件/IT服务、仪器仪表`

面板只对**当前列表里存在的卡片**生效，所以要按岗位名逐条重新搜索再点，
不能只加载一次列表就循环点击。

### 福利要自己从 JD 里解析

`welfareLabel` 字段在列表数据里**恒为空**，平台的福利写在 JD 的「薪资福利」段落里，
形如「五险一金、商业医疗保险、绩效奖金、年度体检、带薪年假」。

`_extract_welfare()` 用关键词表从面板文本里扫，并做子串去重
（有「五险一金」就不重复记「五险」）。部分岗位的 JD 确实不写福利，留空是正常的。

### HR 活跃：平台不提供

翻遍 Vue 数据的 100+ 字段也没有 HR 活跃或在线状态（只有 `chatWindow` 这个布尔值）。
这是智联的产品设计，不是抓漏。不要在这上面继续找。

### 城市参数

URL 形式 `https://www.zhaopin.com/sou/jl703/p1?kw=<关键词>`，`jl703` 是青岛。
注意页面会 302 到 `https://www.zhaopin.com/jobs/?jl=703&kw=...`，但列表照常渲染。

## 前程无忧（51job）

**字段最全，且结构化程度最高。**

### 卡片内嵌 JSON

每个 `.joblist-item` 有 `sensorsdata` 属性，是个 JSON 字符串：

```json
{
  "jobId": "173231504",
  "jobTitle": "Java开发（AI智能体）",
  "jobSalary": "1-1.2万",
  "jobArea": "青岛·黄岛区",
  "jobYear": "5年及以上",
  "jobDegree": "大专",
  "jobTime": "2026-08-11 17:53:02"
}
```

`jobTime` 就是**上架时间，精确到秒**。这是四个平台里唯一直接给的。

### 福利在 `.tag` 里

技能标签和福利标签混在同一个 `.tag` 列表里，技能在前、福利在后，靠关键词区分。

关键词表要覆盖实际写法，否则会漏掉一大半：

```
周末双休 / 双休 / 单休 / 大小周 / 五险一金 / 全额五险一金 / 六险一金
年终奖金 / 绩效奖金 / 项目奖金 / 股票期权 / 带薪年假 / 法定假期
定期体检 / 员工旅游 / 免费班车 / 员工宿舍 / 餐饮补贴 / 加班调休 / 节日福利
```

早期版本只用了「五险/双休/年假」这类短词，漏掉了「周末双休」「全额五险一金」
「法定假期」「加班调休」——这些是 51job 最常见的福利写法。

### 详情页

`https://jobs.51job.com/all/{jobId}.html`，含完整 JD、工作地址、公司简介。
地址优先取 `地图完整地址：` 后的文本，比 `工作地址` 段干净（后者混入地图组件噪声）。

### 注意浏览器兼容性检测

51job 会检测 `load_mode`。如果设成 `eager` 会跳"你的浏览器可能存在兼容性问题"页，
导致卡片数为 0。**不要启用 eager 模式**。

## 猎聘

### 卡片文本形态

```
岗位名
【青岛-市南区】
10-18k·15薪
3年以上本科        ← 经验和学历挤在一行，需拆
公司名
IT服务100-499人    ← 行业 + 规模粘连
```

经验/学历用 `_split_exp_edu` 拆：分别正则匹配 `经验不限|应届|\d+-?\d*年` 和 `本科|硕士|博士|大专|学历不限`。

### 公司名常被隐藏

显示为"某知名公司""某青岛大型IT服务公司"是猎聘的保护机制，不是解析失败。
拿不到时兜底成「（猎聘未披露）」。

### 风控最严

容易触发 `safe.liepin.com/v/intercept/verifysms` 短信验证，需要账号主人手动过。

**自动兜底**：检测到拦截时改用 `liepin-cli`（实现在 `adapters/liepin_cli.py`）：

```python
# 探测：Windows 上必须找带扩展名的可执行文件
liepin_cli._resolve_cmd()   # 找 .exe / .cmd / .bat
liepin_cli.available()      # 能否执行
liepin_cli.auth_ok()        # token 是否有效
```

CLI 走独立接口通道，不受浏览器风控影响，但**只有 `search` 和 `apply`，没有详情接口**。
所以兜底能保住列表字段，JD / 地址 / HR 活跃仍为空。

### 详情页有结构化公司信息

`https://www.liepin.com/job/{id}.shtml`，SPA，需要 `scroll.to_bottom()` 触发懒加载后再读。

页面底部「公司信息」区是**带字段前缀**的，比正则猜更准：

```
企业行业：互联网
人数规模：2000-5000人
职位地址：青岛-崂山区青岛特来电新能源有限公司
注册时间：2014年09月
注册资本：92998.00万人民币
经营范围：许可项目：...
```

- 行业用「企业行业：」匹配
- 规模用「人数规模：」匹配
- **地址用「职位地址：」**——这是四个平台里最干净的地址来源

HR 活跃在页面顶部，形如「刘女士一周前在线」或「谢女士21小时前在线」。
注意「一周前在线」这种中文表达的也要覆盖，只写 `\d+小时` 会漏。

### JD 必须用容器截取，不能按关键字往后切

页面底部有侧边栏推荐其他岗位，按「职位介绍」关键字往后截 2000 字会把别的岗位
标题混进来，比如：

```
... 聊一聊 Vue前端工程师（双休五险一金） 【青岛-市北区】 8-12k 来个苹果 ...
```

这会导致「双休」「五险一金」被误判成本岗位的福利。

正确做法：用 `[class*="job-intro"]` 容器取文本（实测约 280 字符，只含本岗位）。
容器不存在时才退回关键字截取，且要截到「聊一聊」之前。

### 福利没有独立字段

猎聘不提供福利标签，只能从 JD 正文里扫关键词。很多岗位的 JD 只写「福利待遇：面谈」
甚至完全不提，所以福利字段大面积为空是正常的。单双休同理，只在 JD 写了才有。

### 详情页限流

连续打开 10+ 条详情页很容易触发短信验证。`enrich` 里检测到风控立刻停，
不要重试——重试只会加重风控。验证通过后要**立刻**补详情，窗口期大约十几分钟。

## 通用注意

### 浏览器单例

DrissionPage 在同一 user-data-dir 上重复实例化会互踢连接，报
`PageDisconnectedError: 与页面的连接已断开`。`core/browser.py` 保证进程内只有一个
ChromiumPage，连接失效时重建一次。

各适配器**不要**自己持有 `page` 引用跨多次导航——连接重建后旧引用失效。
每次操作前调 `get_page()` 取当前对象。

### 节流

`safe_get` 内置：每次导航间隔 2-4.5 秒随机，每 8 次导航强制冷却 8 秒。
平台间切换额外冷却 15 秒（`platform_cooldown`）。

### 风控检测

`browser.is_blocked(page)` 统一识别：
- `safe.liepin.com` / `verifysms` → 猎聘短信验证
- `_security_check` → BOSS 安全校验
- `captcha` / `verify` → 验证码

新增平台时把特征加到 `is_blocked` 里，这样 `collect` 能统一提示用户。
