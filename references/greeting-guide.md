# 求职者画像 · 模板

怎么写招呼语，靠的是这份画像。它**不属于 skill**，属于你个人——放在数据目录里，
升级 skill 不会覆盖。

## 位置

```
$JOBHUNT_HOME/profile.md        # 例：./job-data/profile.md
```

`greet --export` 会读它，并把画像摘要附在输出里。文件不存在时导出仍可用，
但招呼语只能写通用版（提不了你的具体项目）。

## 初始化

```bash
python -m scripts.main greet --init-profile
```

会在 `$JOBHUNT_HOME/profile.md` 生成一份带占位符的模板，你按自己情况填。
如果本地有简历，也可以直接把简历内容摘进去——不用严格按格式。

## 建议结构

```markdown
# 求职者画像

## 基本信息
- 工作年限：3 年
- 城市：青岛
- 学历：本科 · 某某大学 · 计算机科学与技术 · 2022 届

## 按方向的简历（可选）
有两个以上方向时列出来，写招呼语时按岗位 JD 挑最贴的：

| 方向 | 简历 | 何时用 |
|---|---|---|
| 前端 | resume-frontend.pdf | 纯前端岗 |
| 全栈 | resume-fullstack.pdf | 要求前后端都做 |

## 核心技术栈
- 主力：Vue 3 / TypeScript / Vite
- 后端：Python FastAPI / Node
- 其他：Canvas、ECharts、Docker

## 项目弹药
写招呼语时从这里挑，**只引用真实发生过的**：

- **项目名**（年份）— 一句话定位
  - 你负责的部分
  - 有数字的成果：性能提升 30%、代码减少 60%、日均 200+ 次
  - 用到的关键技术

（列 3–6 个最有说服力的，越具体越好）

## 写作要点
- 开头直接点岗位名，不要「您好，我是…」
- 中间 1–2 句对应 JD 的具体要求
- 优先用数字
- 不超过 200 字
- 不写薪资期望
- 不编造画像里没有的技术和项目
```

## 为什么要画像而不是模板拼接

招呼语要打动 HR，靠的是「你说的事正好是我们岗位要的」。这需要读懂 JD 后判断
哪段经历最贴——是语义匹配，不是关键词替换。所以本项目的做法是：脚本准备材料
（JD + 画像），由 agent 逐条撰写，脚本只负责校验和落库。

这也是为什么其余部分（打分、外包判定）是纯本地规则，而招呼语这一环需要 agent：
前两者是分类，后者是写作。
